# Vitamin CHE PWA — локальная тестовая версия

Приложение для личного тестирования владельцем продукта. Это не публичный релиз и не замена мобильной сборке v1.0.

## Источники и приоритет

- Требования и экранные материалы находятся в [основном репозитории Vitamin CHE](https://github.com/Chemezova/vitamin-che); сверяйся с его `02-product/tz/`, `02-product/dev-screens/` и `02-product/mvp/`.
- Оригинальные справочники лежат в vault Елены (`02-product/data/json/`); в этом репозитории хранятся только используемые приложением копии в `data/`.
- При спорном поведении сверяйся с `01-vision/constraints.md`, `00-meta/decisions-log.md` и `00-meta/CONFLICTS.md` в основном репозитории.
- Макет — образец визуального направления; он не меняет продуктовые правила.

## Правила разработки

- Постоянные техрешения записаны в `TECH_STACK.md`; потоки данных — в `ARCHITECTURE.md`; шаги — в `TODO.md`.
- Перед изменением добавь новый пакет или обновлением версии сначала согласуй это с Еленой. Сейчас зависимостей нет.
- Здесь нет сборки TypeScript: в JavaScript-файлах оставлять `// @ts-check` и JSDoc для структур.
- Ни один личный ввод не отправлять в сеть. Разрешены только локальные файлы справочников и открытие источника по нажатию пользователя.
- Не менять автоматически расписание, курс, отметки и остаток. Отметка/отмена/редактирование — только по действию человека.
- Дозу не пересчитывать. Не суммировать одинаковое вещество из нескольких банок.
- Подсказки брать только из справочника со статусом `published` или `wiki_only`, показывать источник; не советовать, что менять.
- Пейволл — демонстрационный экран. Не подключать оплату, тарифы и Premium entitlement.
- Перед показом текста человеку сверить его с юридической рамкой основного проекта и навыком `legal-check`.
- Данные человека не добавлять в Git, исходники, журнал ошибок и примеры. Образцы в `store.js` вымышлены.

## Как запускать

Это статическая PWA без сборки и установки зависимостей. Запускай локальный сервер из этой папки (например, `py -m http.server 4173`), затем открой `http://localhost:4173`. Для установки на телефон нужен HTTPS; в тестовом контуре пригодится GitHub Pages или другая статическая HTTPS-публикация.

Офлайн-режим обслуживает оболочка Service Worker. Первая загрузка справочников требует сети. Все введённые данные хранятся в IndexedDB только в этом браузере и не синхронизируются между устройствами. Оригинальные документы vault не правятся из этого репозитория.
