# Vitamin CHE PWA — личный тест

Адаптивная устанавливаемая PWA по наработкам Vitamin CHE. Точка входа — четыре вкладки: Today, Plan, Progress и Settings. Интерфейс доступен на английском и русском; язык устройства используется при первом запуске, переключение можно изменить в настройках.

## Что уже работает

- Демонстрационный экран ленты дня, отметка приёма/пропуска, отмена и списание остатка банки.
- Добавление, редактирование и пауза пунктов полки, количество за приём, расписание по дням недели и заметка.
- Выбор банки из локальной витрины ТОП-10 или ручное добавление; дозу и схему тестировщица вводит сама по этикетке.
- Цели и личные записи, график записей рядом с историей приёма без автоматической интерпретации связи.
- Пункты рутины и отметки дня, самочувствие, вода, движение.
- Остатки на полке, история за неделю, локальная выгрузка записей в JSON.
- Offline-shell, установка PWA на устройство при публикации через HTTPS.
- Справочные данные сочетаний со статусом публикации и ссылкой на источник.

## Что здесь имитируется

Тестовая версия не содержит сервера, аккаунта, платежей, подтверждения Premium, синхронизации или push-сервиса. Панель оплаты — информационная заглушка; реальные цены и оплаты не используются. Напоминание браузера может работать только пока страница открыта и разрешены уведомления. Часть экранов/логики мобильной v1.0 остаётся в TODO; это ранняя личная сборка, а не выпуск всего 30-экранного потока.

Все данные этой сборки хранятся в IndexedDB текущего браузера. При потере/смене устройства они не переедут. Записи не загружаются в GitHub и не уходят в сеть. В демонстрационном наборе — условные примеры.

## Локальный запуск

Из папки `pwa/`:

```powershell
py -m http.server 4173
```

Открой `http://localhost:4173`. Для установки на телефон нужен HTTPS-хостинг. Техстек и потоки данных — в `TECH_STACK.md` и `ARCHITECTURE.md`.

## Связь с основным проектом

Это отдельная тестовая реализация. Исходные документы, задачи и дашборд проекта остаются в vault и не изменяются из этого репозитория. Для сверки используй [проектный репозиторий](https://github.com/Chemezova/vitamin-che), [рабочий дашборд](https://claude.ai/artifact/54udDt9YWk6AT47z5rz9rk#overview) и экранные материалы в нём. Копии справочников в `data/` обновляются вручную из vault отдельной командой; они не синхронизируются автоматически.
