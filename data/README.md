# Локальные справочники PWA

Это копии пяти наборов из `02-product/data/json/` основного vault: реестр сочетаний, маркеры, витрина ТОП-10, каталог и этикетки. Источник истины — CSV/YAML в базе продукта и сгенерированные JSON в приватном проекте Vitamin CHE, а не файлы в этой папке.

После подтверждённого обновления справочников запусти из корня этого репозитория, указав путь к локальному vault:

```powershell
py scripts/sync_pwa_data.py --source-root "C:\\путь\\к\\vault"
```

Скрипт копирует только наборы, нужные приложению. В пользовательские записи эти JSON не попадают. Не добавляй сюда пользовательские значения и свободный текст.
